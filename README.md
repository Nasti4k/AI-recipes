# AI-рецепты
Веб-приложение на **FastAPI**, которое генерирует структурированные кулинарные рецепты с помощью языковых моделей (LLM). Достаточно описать блюдо или ввести запрос — и вы получите готовый рецепт в едином формате: ингредиенты, шаги приготовления, время, порции и советы.
## Особенности
- **Строгий JSON-формат ответа** — все рецепты выглядят одинаково благодаря системному промпту-«редактору» и валидации через Pydantic.
- **Устойчивость к ошибкам API** — обработка `RateLimitError`, `APIConnectionError` и `APIError` с понятными сообщениями на русском языке.
- **«Очистка» ответа модели** — удаление тегов `<think>`, `<reasoning>` и markdown-обёрток ``` перед парсингом JSON.
- **Простой фронтенд** — Jinja2-шаблон + JS, без сборщиков и фреймворков.
## Технологии
| Компонент | Что используется |
|---|---|
| Бэкенд | FastAPI, Uvicorn |
| LLM-клиент | OpenAI SDK (AsyncOpenAI) — совместим с любым провайдером с OpenAI-совместимым API |
| Валидация | Pydantic v2 |
| Шаблоны | Jinja2Templates |
| Фронтенд | HTML / CSS / JavaScript |

## Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Nasti4k/AI-recipes.git
   cd AI-recipes
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install fastapi uvicorn openai pydantic jinja2
   ```
3. В файле `config.py` укажите свои параметры:
   ```python
   API_KEY = "ваш_api_ключ"
   BASE_URL = "https://api.openai.com/v1"   # или URL другого провайдера
   MODEL = "название_модели"
   ```
4. Запустите сервер:
   ```bash
   uvicorn main:app --reload
   ```
5. Откройте в браузере: **http://127.0.0.1:8000**
## API
### `POST /products/ai/`
Генерация рецепта по текстовому запросу.
**Запрос:**
```json
{
  "prompt": "Придумай рецепт пасты с томатами и базиликом"
}
```
**Ответ (200):**
```json
{
  "title": "Паста с томатами и базиликом",
  "description": "...",
  "time_minutes": 25,
  "servings": 2,
  "difficulty": "легко",
  "ingredients": [
    { "name": "спагетти", "quantity": "200 г" },
    { "name": "томаты", "quantity": "3 шт" }
  ],
  "steps": ["Отварите спагетти до готовности.", "..."],
  "tips": "..."
}
```
**Коды ошибок:**
| Код | Описание |
|---|---|
| `429` | Слишком много запросов — подождите минуту |
| `502` | Ошибка AI / модель вернула невалидный JSON или схему, не совпадающую с Recipe |
| `504` | Не удалось подключиться к AI — проверьте интернет |

## Схема рецепта (Pydantic)
Модель `Recipe` строго проверяет ответ модели:
- `title: str` — название блюда
- `description: str` — краткое описание
- `time_minutes: int` — время приготовления в минутах
- `servings: int` — количество порций
- `difficulty: str` — сложность
- `ingredients: list[Ingredient]` — ингредиенты (`name`, опционально `quantity`)
- `steps: list[str]` — шаги приготовления
- `tips: str | None` — совет (или дополнительный ответ на вопрос)
Если ответ модели не проходит валидацию — возвращается `502` с текстом ошибки.
